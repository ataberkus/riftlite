# riftlite

A lightweight desktop companion for **League of Legends** and **Teamfight Tactics** on Windows.
It is one native Rust process (egui/OpenGL). There is no embedded browser, no script runtime, no account, no injection and no elevation.

## Features

| Feature | Data source |
|---|---|
| League/TFT install detection | `%ProgramData%\Riot Games\RiotClientInstalls.json`, Riot Client product metadata, `HKCU\…\Uninstall\Riot Game <product>.live`, or a League folder chosen in Settings |
| Running detection (Riot Client, League client, League game, TFT client/game) | Win32 process snapshot |
| Launch League / TFT | `RiotClientServices.exe --launch-product=<id> --launch-patchline=live` |
| League client (LCU) connection | `LeagueClientUx.exe` command line (`--app-port`, `--remoting-auth-token`), with `lockfile` fallback |
| Gameflow phase, queue, map, players of the starting game | LCU `/lol-gameflow/v1/gameflow-phase`, `/lol-gameflow/v1/session` |
| Profile: Riot ID, level, ranked queues, champion mastery, challenges, open missions | LCU `/lol-summoner/v1/current-summoner`, `/lol-ranked/v1/current-ranked-stats`, `/lol-champion-mastery/v1/{puuid}/champion-mastery`, `/lol-challenges/v1/summary-player-data/local-player`, `/lol-missions/v1/missions` (on demand) |
| LoL match history, 20 at a time, with a full 10-player scoreboard per game | LCU `/lol-match-history/v1/products/lol/current-summoner/matches?begIndex=&endIndex=`, `/lol-match-history/v1/games/{gameId}` |
| Player lookup by Riot ID: rank, mastery, history, spectate | LCU `/lol-summoner/v1/alias/lookup`, `/lol-ranked/v1/ranked-stats/{puuid}`, `/lol-match-history/v1/products/lol/{puuid}/matches`, `/lol-spectator/v1/spectate/launch` |
| TFT match history (last 20): placement, traits, board | LCU `/lol-match-history/v1/products/tft/{puuid}/matches` |
| Auto-accept the ready check (off by default) | LCU `/lol-matchmaking/v1/ready-check` → `POST /lol-matchmaking/v1/ready-check/accept`, queried only while the gameflow phase is `ReadyCheck`; a check you already accepted or declined is left alone |
| Champ select: both teams with ranks, bans, ARAM bench with one-click swap, ARAM champion cards ("Pick a champion", e.g. ARAM Mayhem) with one-click pick, your record on the pick, your strongest available picks | LCU `/lol-champ-select/v1/session` (`allowSubsetChampionPicks`), `/lol-lobby-team-builder/champ-select/v1/subset-champion-list`, `PATCH /lol-champ-select/v1/session/actions/{id}`, `/lol-champ-select/v1/pickable-champion-ids`, `/lol-champ-select/v1/session/bench/swap/{id}`, `/lol-ranked/v1/ranked-stats/{puuid}` |
| Runes and summoner spells applied on lock-in (or by button): Riot's recommended page, or (Settings) the OP.GG page and spells you picked; with OP.GG, lock-in waits up to 20 s for its answer and falls back to Riot's page with the reason logged | LCU `/lol-perks/v1/recommended-pages/champion/{id}/position/{pos}/map/{map}` → one page named `riftlite: <champion>` via `/lol-perks/v1/pages` + `/lol-perks/v1/currentpage`; spells via `PATCH /lol-champ-select/v1/session/my-selection` |
| Swiftplay: recommended runes and spells for both pre-picked champions | LCU `/lol-lobby/v1/lobby/members/localMember/player-slots` |
| OP.GG builds in champ select: up to 15 core builds for your mode and lane (ranked, flex, ARAM, URF, Nexus Blitz, Arena), grouped AP / AD / On-hit / Crit / Tank / Utility (classified from Data Dragon item stats and tags, not names; every build is in at least one group); groups ordered by their best build, builds within a group by the low end of their win rate's 95% Wilson range (so few lucky games cannot outrank a much-played build), each with its ±95% margin, games and pick rate, wide margins marked "few games"; the build you pick is remembered per champion and mode; a warning when OP.GG's patch differs from the game's; Retry after a failed answer | OP.GG's champion data endpoint `https://lol-api-champion.op.gg/api/global/champions/{mode}/{id}/{lane}` (`arena/{id}` for Arena; the JSON behind op.gg's champion pages; sends only champion id, mode and lane; Emerald+ for ranked and flex); Data Dragon `item.json`; picks in `%LOCALAPPDATA%\riftlite\builds.json` |
| OP.GG options next to the build: trusted alternative starting items and boots, up to 5 skill orders (each with OP.GG's max order), rune pages and summoner-spell pairs to pick from; the picked rune page and spells become the OP.GG page next to Riot's recommended pages | Same OP.GG answer |
| Lane matchups: your champion's OP.GG lane win rate against each enemy pick (ranked and flex), "your lane" when the client shows the enemy's position | Same OP.GG answer (`counters`); LCU champ select session for enemy picks |
| Item sets on lock-in: the picked OP.GG build in Starting (with the picked skill order's max order) / Core (in order) / Boots / Full build / Situational blocks, OP.GG's other starts and boots, the best build of each other group as Alternative blocks, plus your best recent game in this mode; picking another build or skill order after lock-in rewrites the set; your own build from this mode alone when OP.GG is off, unreachable or has no build with 100+ games; any past or just-finished game's build on demand; writing a set deletes Blitz's leftover sets so they no longer show next to it (your own and other tools' sets stay); remove all of riftlite's sets again | Same OP.GG answer; your own LCU match history → `<League>/Config/Champions/<Champion>/Recommended/riftlite_meta_<id>_<mode>.json` / `riftlite_<gameId>.json` (Arena sets on map 30); Blitz's sets are `<League>/Config/Global/Recommended/!!!blitz-<n>.json` |
| Champion browser: Riot's recommended runes per position and for ARAM, your stats and mastery per champion | LCU `/lol-perks/v1/recommended-champion-positions`, recommended pages, your history |
| Live game: scoreboard with ranks, item value per player/team/lane, objective timers, CS/min benchmark, recorded skill order; the main window is restored and brought to the front when the gameflow phase enters `InProgress` | Riot Live Client Data API `https://127.0.0.1:2999/liveclientdata/allgamedata` (players, items with prices, event feed, ability levels); LCU `/lol-gameflow/v1/gameflow-phase` |
| In-game overlay: clock, KDA, CS/min vs your average, team and lane item-value difference, dragon/Elder/Baron/inhibitor timers, "level up Q" hint, enemy respawns; enemy ranks on the loading screen and for the first 90 s; each section can be turned off | Same Live Client Data API plus gameflow session ranks; separate always-on-top, click-through, never-activated window, by default shown only while the game window is in the foreground (out-of-context `SetWinEventHook(EVENT_SYSTEM_FOREGROUND)`; Settings → Overlay can turn that off); Ctrl+Shift+O or the tray menu hides it |
| Overlay edit mode: Ctrl+Shift+E, the tray menu or Settings → Overlay makes the overlay clickable with an accent border; drag it to move it, drag the corner grip to resize it, tick the sections to show; outside a game it shows sample data. Done or Ctrl+Shift+E makes it click-through again. Position, size and sections are also editable in Settings → Overlay | Native window move/resize (`ViewportCommand::StartDrag` / `BeginResize`); saved as `overlay_pos`, `overlay_size`, `overlay_sections` in `%LOCALAPPDATA%\riftlite\settings.json` (older `overlay_margin_*` offsets are converted once) |
| ARAM Mayhem augment tiers: when the augment cards are shown, an S/A/B/C/D badge under each card (next to its reroll button), "?" when Blitz has no tier for it; the overlay panel credits Blitz or says why tiers are missing (Settings, on by default) | Offered cards: the cards' title strip of the game window, copied from the screen (GDI `BitBlt` of the screen device context, as a screenshot) about every 0.2 s while a `KIWI` game is focused, read with Windows' built-in OCR (`Windows.Media.Ocr`) in the client's language (LCU `/riotclient/region-locale`), and matched to ids by the client's names (LCU `/lol-game-data/assets/v1/cherry-augments.json`, Mayhem `ARAM_` entries preferred over Arena ones with the same name); tiers: `https://data.v2.iesdev.com/api/v1/query_objects/prod/lol/aram_mayhem_augments`, the JSON behind blitz.gg's ARAM Mayhem augment tier list (rank 1–5 = S–D, checked against the letters on that page), fetched once per 6 h |
| Post-game: result, LP change, scoreboard, insights versus your own averages in that queue | LCU `/lol-end-of-game/v1/eog-stats-block`, `/lol-ranked/v1/current-lp-change-notification`, your history |
| Skill orders | Recorded by riftlite from the Live Client API while you play; `%LOCALAPPDATA%\riftlite\skills.json` |
| Champion, item, summoner spell and rune names and images (portraits, splash art, item/spell/rune and profile icons) | Riot Data Dragon (`ddragon.leagueoflegends.com`), cached per patch (images in `%LOCALAPPDATA%\riftlite\ddragon\<patch>\img`); ids Data Dragon lacks (mode-only items, stat shards) from the client's `/lol-game-data/assets/v1/*.json` |
| Tray icon (open / hide overlay / edit overlay layout / quit), start with Windows (minimized), settings | `Shell_NotifyIconW`; Ctrl+Shift+O / Ctrl+Shift+E through a low-level keyboard hook (`SetWindowsHookExW(WH_KEYBOARD_LL)`, so they also work in the League game, which suppresses `RegisterHotKey` hotkeys), plus `RegisterHotKey` for elevated foreground windows; `HKCU\…\Run`, `%LOCALAPPDATA%\riftlite\settings.json` |

## Limitations

- TFT data (ranked and match history) comes only through the League client's LCU. When TFT runs in the standalone TFT client without the League client, there is no LCU to read from.
- No champion tier lists, pro builds, jungle paths or news. Aggregated builds come from OP.GG (with source credit, as OP.GG asks) and cover ranked solo/duo and flex (Emerald+ games, OP.GG's default filter), ARAM (also used for ARAM Mayhem, which OP.GG does not track separately; Mayhem's augments can change which items are strong), URF, Nexus Blitz and Arena (all games); other modes fall back to your own builds. Arena shows items only: OP.GG lists augments by id, and riftlite does not show Arena augments. Lane matchup win rates exist only for ranked and flex, and champ select rarely shows which lane an enemy plays. The OP.GG endpoint is the undocumented one its website uses (OP.GG's public MCP server lists only one core build), so it may change without notice; riftlite then says the format changed and uses your own builds. Benchmarks, suggestions and insights use your own games only.
- ARAM Mayhem augment tiers are read off the screen because neither the Live Client Data API (its `/Help` lists only `liveclientdata` player, score, rune, item, spell and event endpoints) nor the LCU says which augments are offered. They need Borderless or Windowed mode, the game window focused, and a Windows OCR language for the client's language (Settings > Time & language > Language). The card positions were measured at 16:9 (1280×720, 1920×1080); other aspect ratios or HUD scales are unverified. Tiers are Blitz's overall tiers, not per champion. Blitz's endpoint is undocumented and used without Blitz's permission, so it may change or be blocked; riftlite then shows "?" and the reason. Riot's developer policy says products "cannot display win rates for Augments"; this is a local opt-out setting, not an approved product.
- No ultimate/summoner-spell cooldown tracking, ward/trinket timers, ARAM relic timers or jungle camp timers. The Live Client API does not expose them, and riftlite does not read game memory. Objective timers cover dragon, Elder, Baron and inhibitors, from the game's event feed. Inhibitor respawns are timed on Summoner's Rift only; elsewhere they show time since destroyed.
- No clip recording.
- Skill-order hints need at least one earlier game on that champion played with riftlite running.
- Champion and item names follow Data Dragon's `en_US` data. Live-game item names and the client's recommended-page labels come from Riot in the client's locale.

The overlay is drawn over the game only in **Borderless** or **Windowed** display mode. Exclusive fullscreen would need DLL injection, which riftlite does not do.

## Security model

- **Riot loopback TLS is pinned.** The LCU and Live Client Data API certificates must be issued and signed by Riot's "LoL Game Engineering Certificate Authority", which is embedded from `assets/riotgames.pem`. Certificate verification is never disabled.
- **No code-loading surface.** There is nothing like Electron's RunAsNode, `NODE_OPTIONS` or `--inspect`, no `file://` protocol handler, and no remotely served UI.
- **Never touches game processes.** riftlite does not inject into, write to, or read the memory of any game process. The League client's command line is read with `PROCESS_QUERY_LIMITED_INFORMATION` only. For ARAM Mayhem augment tiers it copies a strip of the screen over the focused game window (as a screenshot does) and reads it with Windows' OCR; the pixels never leave the PC.
- **Writes only what you enable.** Client writes are limited to: accepting a ready check, riftlite's own rune page (never your pages), summoner spells, a bench swap, picking an offered ARAM champion card, Swiftplay slot runes, spectate requests, item-set files prefixed `riftlite_`, and deleting Blitz's `!!!blitz-<n>.json` item sets when it writes one. Each is a setting or a button.
- **No admin rights.** It needs no administrator rights and installs no certificates or services.
- **No telemetry and no ads.** Network traffic goes only to 127.0.0.1 (Riot's local APIs), Data Dragon, when "Use OP.GG builds" is on, `lol-api-champion.op.gg` with the picked champion's id, mode and lane, and, when "ARAM Mayhem: show augment tiers" is on, `data.v2.iesdev.com` (Blitz's augment tiers; a plain GET with nothing about you or the game).

## Build

```
cargo build --release
```

The output is `target\release\riftlite.exe`, a single file with no installer. Start it with `--minimized` to start minimized.

Embedded assets: `assets/logo.png`, `assets/banner.jpg` and `assets/riftlite.ico` (made for riftlite; `build.rs` embeds the icon and version info into the .exe with `embed-resource`, which needs the Windows SDK's `rc.exe`), and the Inter and Barlow Semi Condensed fonts in `assets/fonts/` (SIL Open Font License 1.1, license texts alongside). Rank emblems and UI icons are drawn in code.
